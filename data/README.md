# Fashion-MNIST portfolio sample

`fashion_mnist_kaggle_sample.csv` is a compact 1,000-row CSV sample of Fashion-MNIST used for the portfolio evidence. It contains 784 pixel columns and one label column (`y`).

Kaggle dataset page: https://www.kaggle.com/datasets/zalando-research/fashionmnist/data

The compact CSV was obtained from a public CSV mirror of Fashion-MNIST so the GitHub Pages portfolio can remain small and the Python evidence can run quickly. For a full experiment, download the complete Kaggle training and test CSV files and adapt the input path in the script. Fashion-MNIST is licensed under the MIT License by Zalando SE.

## Rice (Cammeo and Osmancik)

`Rice_Cammeo_Osmancik.arff` is the complete 3,810-record dataset used by
Artifact 4. It contains seven image-derived morphological measurements and the
target labels Cammeo and Osmancik. Source: UCI Machine Learning Repository,
https://doi.org/10.24432/C5MW4Z. The dataset is licensed CC BY 4.0.
